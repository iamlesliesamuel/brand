# App icons

- **For apps and browsers:** `ls-app-icon-512.png`, `ls-app-icon-192.png`, `apple-touch-icon-180.png` and `ls-app-icon-square.svg` are full-bleed squares (navy to every edge). iOS and Android round the corners themselves; an icon that's already rounded shows black corners on iPhone. `ls-app-icon-maskable-512.png` has extra padding for Android's shaped icons. Favicons are `favicon.ico` and `favicon-16/32/48.png`.
- **For showing the icon in a document or slide:** `ls-app-icon.svg` has rounded, see-through corners. Never use it as an app icon.
